# Pokémon Emerald Kaizo

This is a recompilation of Pokémon Emerald Kaizo.

The patch files can be found [here](https://github.com/anastarawneh/pokeemeraldkaizo/releases/latest).

This repository only includes the releases, I do not want to host the source code on GitHub. [It can be found here](https://git.anastarawneh.com/anas/pokeemeraldkaizo), but I'm having a little trouble hosting that, so this serves as a mirror for downloads.
